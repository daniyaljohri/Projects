# olist_draft: the unedited auto-drafted pack

This pack is exactly what `python -m askit init --pack olist_draft --schema chatbot` produced on 2026-11-11, before any human review. It is kept unchanged as the control in the evaluation: the same questions run on this pack and on the curated `olist` pack, so the difference in accuracy measures what human review of a drafted pack adds.

Don't use it for real questions; use `packs/olist`. Results are in `eval/results/` (tag `drafted`).
